# Установка GRLS Product Analyzer в Codex

Инструкция предназначена для Windows и версии плагина `grls-product-analyzer`.

## Что устанавливается

Плагин включает:

- skill `$grls-product-analysis` для сценария анализа;
- локальный MCP-сервер для чтения `.xlsb`, `.xlsx` и `.csv`;
- встроенную базу ГРЛС;
- создание автономного HTML-отчёта;
- возможность передавать обновлённую базу ГРЛС ZIP-архивом через чат.

Обработка выполняется локально. Product list, пользовательские обновления базы и отчёты не добавляются в репозиторий автоматически.

## Требования

Перед установкой проверьте:

1. Установлен ChatGPT Desktop/Codex с поддержкой plugins.
2. Установлен Python версии 3.10 или новее.
3. Команды `python` и `codex` доступны из PowerShell.
4. У пользователя есть права на запуск локальных программ и создание файлов в пользовательской папке.

Проверка Python:

```powershell
python --version
```

Проверка Codex CLI:

```powershell
codex --version
```

Если одна из команд не найдена, сначала установите соответствующий компонент и перезапустите PowerShell.

## Вариант 1. Установка из ZIP-архива

Это самый простой способ для единичной установки.

### Шаг 1. Распакуйте архив

Распакуйте `grls-product-analyzer-github-0.2.0.zip` в отдельную папку, например:

```text
C:\Tools\grls-product-analyzer
```

После распаковки в корне должны находиться:

```text
C:\Tools\grls-product-analyzer\install.ps1
C:\Tools\grls-product-analyzer\.agents\plugins\marketplace.json
C:\Tools\grls-product-analyzer\plugins\grls-product-analyzer\.codex-plugin\plugin.json
```

Если после распаковки получилась лишняя вложенная папка, например `C:\Tools\grls-product-analyzer\grls-product-analyzer-github-0.2.0\install.ps1`, используйте для установки именно папку, где находится `install.ps1`.

### Шаг 2. Запустите установщик

Откройте PowerShell и перейдите в корень распакованного архива:

```powershell
cd C:\Tools\grls-product-analyzer
```

Запустите установку:

```powershell
powershell -ExecutionPolicy Bypass -File .\install.ps1
```

Скрипт:

1. добавит локальный marketplace;
2. установит `grls-product-analyzer`;
3. сохранит плагин в локальном кэше Codex.

Если marketplace уже был добавлен, сообщение об этом можно пропустить: скрипт продолжит установку плагина.

### Шаг 3. Перезапустите Codex

Полностью закройте и снова откройте ChatGPT Desktop/Codex. Затем начните новую задачу.

Откройте каталог плагинов и найдите:

```text
Анализ product list по ГРЛС
```

Убедитесь, что плагин включён.

## Вариант 2. Установка из GitHub

Этот вариант рекомендуется для коллег: обновления можно публиковать в репозитории, а не рассылать ZIP-файлы.

### Шаг 1. Опубликуйте репозиторий

В корне GitHub-репозитория должны находиться:

```text
.agents/plugins/marketplace.json
install.ps1
plugins/grls-product-analyzer/.codex-plugin/plugin.json
plugins/grls-product-analyzer/skills/grls-product-analysis/SKILL.md
plugins/grls-product-analyzer/.mcp.json
```

Репозиторий может быть публичным или закрытым. Для закрытого репозитория у каждого коллеги должен быть доступ к нему.

### Шаг 2. Добавьте marketplace

Замените `owner/repository` на адрес вашего GitHub-репозитория:

```powershell
codex plugin marketplace add owner/repository
```

Если нужен конкретный branch или tag:

```powershell
codex plugin marketplace add owner/repository --ref main
```

### Шаг 3. Установите плагин

```powershell
codex plugin add grls-product-analyzer@grls-product-analyzer-marketplace
```

После этого перезапустите Codex и включите плагин в каталоге.

## Вариант 3. Добавление локального marketplace вручную

Этот вариант полезен для разработки и проверки изменений до публикации.

В PowerShell из корня проекта выполните:

```powershell
codex plugin marketplace add .
codex plugin add grls-product-analyzer@grls-product-analyzer-marketplace
```

После изменения файлов плагина:

1. снова запустите установку или обновление;
2. перезапустите Codex;
3. начните новую задачу.

Codex использует установленную копию плагина, поэтому изменения в исходной папке могут не появиться до повторной установки.

## Проверка установки

Создайте новую задачу и напишите:

```text
Используй $grls-product-analysis и сообщи, какие файлы product list ты можешь обработать.
```

Затем выполните тестовый анализ:

```text
Используй $grls-product-analysis.
Проанализируй product list C:\data\manufacturer.xlsx по встроенной базе ГРЛС.
Создай автономный HTML-отчёт и сохрани его в рабочей папке.
```

Для обновления базы:

1. прикрепите ZIP с новой базой ГРЛС;
2. напишите:

```text
Обнови пользовательскую базу ГРЛС этим ZIP-архивом и используй её для следующего анализа.
```

## Типовые ошибки

### `codex` не найден

Codex CLI не установлен или не добавлен в PATH. Установите/обновите Codex и перезапустите PowerShell.

### `python` не найден

Установите Python 3.10 или новее и включите добавление Python в PATH. После установки проверьте:

```powershell
python --version
```

### Плагин не появился в каталоге

Проверьте:

1. что команда установки завершилась без ошибки;
2. что в проекте есть `.agents/plugins/marketplace.json`;
3. что существует `plugins/grls-product-analyzer/.codex-plugin/plugin.json`;
4. что Codex был полностью перезапущен;
5. что плагин включён в каталоге плагинов.

### MCP-сервер не запускается

Проверьте, что Python доступен именно под командой `python`, а не только через `py`:

```powershell
python --version
where.exe python
```

Также убедитесь, что файл существует:

```text
plugins/grls-product-analyzer/mcp-server/server.py
```

### В отчёте нет ожидаемых строк

Проверьте формат и заголовки исходного product list. Сохраните исходный файл без изменения структуры и передайте его в чат вместе с уточнением, какой столбец содержит МНН или название препарата.

## Обновление плагина

### Если используется GitHub

Получите последние изменения и повторите установку:

```powershell
git pull
codex plugin add grls-product-analyzer@grls-product-analyzer-marketplace
```

Затем перезапустите Codex.

### Если используется ZIP

1. Распакуйте новую версию в новую папку.
2. Запустите `install.ps1` из её корня.
3. Перезапустите Codex.

Не удаляйте пользовательскую базу и отчёты вручную без необходимости: они могут храниться отдельно от каталога установки.

## Что передавать коллегам

Рекомендуемый комплект:

1. ссылку на GitHub-репозиторий;
2. эту инструкцию;
3. краткое описание требований: Windows, Python 3.10+, ChatGPT Desktop/Codex;
4. пример product list без конфиденциальных данных;
5. пример команды для первого анализа.

ZIP-архив удобно использовать как резервный офлайн-вариант, но для регулярного использования лучше GitHub: коллеги смогут получать исправления и обновления базы без повторной рассылки всего архива.

## Ограничения и безопасность

- Плагин запускает локальный Python MCP-сервер.
- Перед установкой коллеги должны проверить содержимое `mcp-server/server.py` и доверять источнику пакета.
- Не включайте в репозиторий реальные product list производителей, пользовательские базы и готовые отчёты.
- Встроенная база ГРЛС является аналитическим источником и не заменяет официальную регуляторную проверку.
