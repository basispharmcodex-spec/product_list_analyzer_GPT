# Текущее состояние проекта

Обновлено: 23.09.2026

## Цель

Сделать переносимый плагин `grls-product-analyzer`, который можно хранить на GitHub, скачать на другой компьютер и использовать в ChatGPT desktop/Codex для анализа product list по ГРЛС.

## Требования пользователя

- Архив ГРЛС должен входить в плагин и использоваться по умолчанию.
- Раз в 30 дней при следующем использовании плагин должен проверить возраст базы и попросить пользователя прикрепить свежий ZIP.
- Пользователь обновляет базу в чате: прикрепляет ZIP и просит обновить ГРЛС.
- Обновление не должно требовать ручного копирования файлов.
- Плагин должен устанавливаться из скачанного репозитория или GitHub marketplace на другом компьютере.
- Анализ МНН остаётся модельным; программный код не выполняет fuzzy-matching и не принимает фармацевтические решения.
- Для рыночного отчёта используется только файл/раздел ГРЛС со статусом `Действующий`; остальные статусные файлы не объединяются с ним.
- Дополнительная ручная проверка цепочек переоформления и отдельный список выбранных РУ больше не нужны.
- Основные показатели — число конкурентных препаратов на рынке и число производителей на рынке. Конкурентным считается уникальное РУ лекарственного препарата из раздела `Действующий` с формой, соответствующей позиции Product List; фармацевтические субстанции в этот показатель не входят.
- В детальной таблице не должно быть графы или фильтра `Статус`.
- Нужны раскрывающиеся фильтры по форме выпуска, типу записи и ЖНВЛП; фильтр производителя/держателя не нужен. В формах должны быть варианты вроде `мазь` и `таблетки`.
- Product list должен приниматься в форматах XLSB, XLSX, CSV и PDF.
- Из заголовка HTML-отчёта удалён текст «Сопоставление МНН производителя с действующими регистрационными удостоверениями российского рынка. Отчёт сохраняет исходные строки и отдельно показывает уникальные РУ.».

## Реализовано

- Подтверждён размер исходного ZIP: 18,35 МБ, допустим для обычного GitHub-репозитория.
- Встроенный архив добавлен как `plugins/grls-product-analyzer/data/grls-default.zip`.
- Добавлена метаинформация с датой базы 21.09.2026 и SHA-256.
- В MCP добавлены рабочие инструменты `get_grls_status` и `update_grls_archive`.
- Все инструменты анализа используют активную базу автоматически, если путь к ZIP не указан.
- Новый ZIP проверяется как архив ГРЛС, копируется атомарно и получает метаданные: дата, SHA-256, размер, статусы и время установки.
- Порог напоминания установлен на 30 дней.
- Skill требует проверять актуальность перед каждым анализом и описывает обновление через прикреплённый ZIP.
- Добавлены переносимый `plugin.json`, `mcp.json`, GitHub marketplace с уникальным именем и установщик `install.ps1`.
- Обновлены пользовательские инструкции и описано ограничение веб-ChatGPT.
- Пользовательское обновление хранится отдельно от установленного пакета, поэтому сохраняется после переустановки плагина.
- Добавлено чтение текстовых PDF с сохранением номера страницы и строки на странице; сопоставление МНН по-прежнему выполняет модель.
- Для PDF добавлена зависимость `pypdf`, которую `install.ps1` устанавливает автоматически при необходимости.
- PDF-сканы без текстового слоя требуют предварительного OCR или исходного файла Excel/CSV.
- Нежелательный подзаголовок удалён как из шаблона будущих отчётов, так и из текущего отчёта `outputs/lok-beta-grls-full-report.html`.
- В отчёт и шаблон добавлены метатеги запрета кэширования. Из-за того что уже открытая `file://`-вкладка могла показывать старую копию, создан гарантированно свежий файл `outputs/lok-beta-grls-full-report-updated.html` без удалённого подзаголовка.

## Важное ограничение платформы

Плагин не может сам начать разговор, когда он не используется. Месячное напоминание срабатывает при первом обращении к плагину после истечения 30 дней. Для календарного сообщения независимо от использования нужна отдельная автоматизация на каждом компьютере.

Веб-ChatGPT не запускает локальный stdio MCP напрямую. Текущая переносимая версия предназначена для ChatGPT desktop/Codex с локальным выполнением. Для веб-ChatGPT нужен удалённый MCP-сервер или Secure MCP Tunnel.
