# GRLS Product Analyzer

Переносимый плагин для ChatGPT desktop/Codex: локальный анализ product list фармацевтического производителя по Государственному реестру лекарственных средств России.

## Возможности

- читает product list в `.xlsb`, `.xlsx`, `.csv` и текстовых `.pdf`;
- содержит встроенную выгрузку ГРЛС по состоянию на 21.09.2026;
- проверяет возраст базы перед анализом и после 30 дней просит прикрепить обновление;
- принимает новый ZIP прямо в чате и устанавливает его в пользовательское хранилище;
- помогает модели проверять МНН без автоматического fuzzy-matching;
- использует для рыночного отчёта только раздел ГРЛС `Действующий` и считает каждый точный номер РУ один раз;
- создаёт автономный HTML с сортировкой, карточками, выгрузкой CSV и фильтрами по типу записи, форме выпуска, ЖНВЛП, МНН и стране держателя;
- отдельно показывает лекарственные препараты и фармацевтические субстанции, конкурентные РУ нужной формы и количество уникальных держателей РУ среди них.

## Быстрая установка на Windows

1. Установите ChatGPT desktop/Codex и Python 3.10 или новее. Установщик автоматически добавит библиотеку чтения PDF.
2. Склонируйте репозиторий либо скачайте и распакуйте ZIP с GitHub.
3. В PowerShell из корня репозитория выполните:

```powershell
powershell -ExecutionPolicy Bypass -File .\install.ps1
```

4. Перезапустите приложение и начните новую задачу.

Для установки непосредственно из GitHub marketplace:

```powershell
codex plugin marketplace add owner/repository
codex plugin add grls-product-analyzer@grls-product-analyzer-marketplace
```

Замените `owner/repository` на адрес опубликованного репозитория.

## Использование

```text
Используй $grls-product-analysis. Проанализируй product list
C:\data\manufacturer.xlsb по встроенной базе ГРЛС.
Сохраняй прогресс и создай автономный HTML-отчёт.
```

Чтобы обновить базу, прикрепите свежий ZIP и напишите: `Обнови встроенную базу ГРЛС этим архивом`.

Текстовые PDF анализируются постранично. Если PDF состоит только из отсканированных изображений, сначала потребуется OCR или сохранение в Excel/CSV.

Подробности находятся в [`plugins/grls-product-analyzer/README.md`](plugins/grls-product-analyzer/README.md).

## Как хранится база

Публичная стартовая выгрузка входит в плагин. Новая база, переданная через чат, сохраняется в пользовательской папке данных вне каталога установки. Поэтому она не попадает в GitHub и не теряется при переустановке плагина. Встроенная база остаётся резервной.

Плагин не может начать разговор, пока он не используется. Месячное напоминание появляется при первом обращении после истечения 30 дней. Для календарного уведомления независимо от использования нужна отдельная автоматизация на каждом компьютере.

## Совместимость с ChatGPT

Пакет использует универсальную структуру Agent Plugins и может храниться в GitHub marketplace. Локальный MCP-сервер работает в ChatGPT desktop/Codex. Веб-ChatGPT не запускает локальный stdio MCP напрямую: для полностью веб-сценария требуется удалённый MCP-сервер либо Secure MCP Tunnel.

## Конфиденциальность

Обработка выполняется локально. В репозиторий входит только публичная стартовая выгрузка ГРЛС. Product lists производителей, пользовательские обновления, рабочие решения и отчёты в репозиторий не записываются.
