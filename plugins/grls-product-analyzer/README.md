# GRLS Product Analyzer

Переносимый локальный плагин ChatGPT desktop/Codex для проверки product list фармацевтического производителя по Государственному реестру лекарственных средств России.

## Что входит в плагин

- MCP-сервер для чтения `.xlsb`, `.xlsx`, `.csv`, текстовых `.pdf` и ZIP ГРЛС;
- встроенная база ГРЛС по состоянию на 21.09.2026;
- проверка актуальности базы при каждом запуске анализа;
- обновление прикреплённым ZIP через GPT без ручного копирования;
- skill для модельной проверки МНН;
- автономный HTML-отчёт с сортировкой, фильтрами, карточками и CSV.

Программный код не определяет МНН и не выполняет fuzzy-matching. Эти решения принимает модель после просмотра сырых значений ГРЛС. Генератор отчёта использует только раздел `Действующий`, выбирает записи с проверенным точным МНН и считает каждый номер РУ один раз. В отчёте отдельно показаны лекарственные препараты и фармацевтические субстанции, а основными показателями служат конкурентные РУ нужной формы и уникальные держатели РУ среди них.

## Требования

- ChatGPT desktop/Codex с поддержкой локальных plugins и stdio MCP;
- Python 3.10 или новее;
- для `.xlsx`, `.csv` и ZIP внешние библиотеки не нужны;
- установщик добавляет библиотеки `pypdf` и `pyxlsb` из `requirements.txt` для чтения PDF и XLSB;
- Microsoft Excel остаётся резервным способом чтения `.xlsb` на Windows.

## Установка

После скачивания или клонирования репозитория запустите `install.ps1` из его корня, перезапустите ChatGPT desktop/Codex и начните новую задачу.

Установка из GitHub marketplace:

```powershell
codex plugin marketplace add owner/repository
codex plugin add grls-product-analyzer@grls-product-analyzer-marketplace
```

## Анализ

```text
Используй $grls-product-analysis. Проанализируй product list
C:\data\manufacturer.xlsb по встроенной базе ГРЛС.
Сохраняй прогресс и создай автономный HTML-отчёт.
```

Путь к архиву ГРЛС в инструментах анализа необязателен. Используется последнее пользовательское обновление, а при его отсутствии — встроенный архив.

В PDF сохраняются номера страницы и строки на странице. Текстовые PDF читаются напрямую; сканы без текстового слоя требуют OCR. Плагин не делает выводы по пустому результату извлечения.

## Обновление ГРЛС через GPT

При первом использовании после 30 дней плагин сообщает дату базы и просит прикрепить свежий официальный ZIP. После прикрепления напишите:

```text
Обнови базу ГРЛС этим прикреплённым ZIP-архивом, затем покажи дату и контрольную сумму активной базы.
```

Новый ZIP структурно проверяется и сохраняется в пользовательской папке вне установки. Встроенная база остаётся резервной. Плагин не может прислать сообщение, пока он не используется; для независимого календарного уведомления нужна отдельная автоматизация.

## Этапы анализа

1. Проверка даты активной базы ГРЛС.
2. Инспекция product list и статусных разделов архива.
3. Определение МНН моделью для каждой строки.
4. Буквальный поиск возможных значений в ГРЛС.
5. Проверка комбинаций, порядка компонентов, написания и солей.
6. Разделение лекарственных препаратов и фармацевтических субстанций по буквальному обозначению формы ГРЛС.
7. Подсчёт конкурентных РУ нужной формы и уникальных держателей РУ среди них.
8. Построение и проверка HTML без отдельного раздела доказательств и без графы статуса.

Рыночный отчёт всегда использует только раздел `Действующий`. Другие статусные файлы архива в него не добавляются.

## Совместимость

Корневые `plugin.json` и `mcp.json` используют переносимый формат Agent Plugins; `.codex-plugin/plugin.json` и `.mcp.json` сохранены для совместимости. Веб-ChatGPT не запускает локальный stdio MCP напрямую: нужен удалённый MCP endpoint или Secure MCP Tunnel.

## Конфиденциальность

Обработка выполняется локально. Не добавляйте product lists, пользовательские обновления ГРЛС, решения и отчёты в публичный репозиторий. Встроенная стартовая выгрузка является публичным исходным набором.
