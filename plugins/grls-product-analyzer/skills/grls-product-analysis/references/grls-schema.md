# Схема выгрузки ГРЛС

## Структура архива

ZIP содержит отдельные `.xlsx` по статусам. Заголовки находятся в строке 5, название статуса — в строке 6, данные начинаются со строки 7.

Для текущего рыночного отчёта используется только раздел `Действующий`.

Не включаются:

- `Выдано по правилам ЕАЭС`;
- `Действует, на подтверждении государственной регистрации`;
- `Действует, в иностранных упаковках`;
- `Изменённый`;
- `Исключённый`;
- `Истёкший`;
- `Приостановлено применение`.

Не объединяйте эти разделы с `Действующий` в одном рыночном показателе.

## Поля записи

| Поле MCP | Поле ГРЛС | Использование |
| --- | --- | --- |
| `registration_number` | Номер регистрационного удостоверения | Точный идентификатор; одинаковый номер считать один раз |
| `registration_date` | Дата регистрации | Сортировка и анализ возраста регистрации |
| `expiration_date` | Дата окончания действия РУ | Контекст статуса; пустое значение не трактовать самостоятельно |
| `cancellation_date` | Дата аннулирования РУ | Контекст статуса |
| `holder` | Юридическое лицо, на имя которого выдано РУ | Держатель РУ |
| `holder_country` | Страна держателя | География держателя |
| `trade_name` | Торговое наименование | Не использовать как ключ уникальности |
| `inn` | Международное непатентованное или химическое наименование | Сопоставлять после модельной проверки |
| `release_forms` | Формы выпуска | Содержит форму, дозировку, упаковку и отпуск; сохранять исходный текст |
| `manufacturing_stages` | Сведения о стадиях производства | Производители и стадии |
| `normative_documentation` | Нормативная документация | Трассировка документов |
| `pharmacotherapeutic_group` | Фармакотерапевтическая группа | Дополнительный рыночный контекст |
| `ved` | Наличие в перечне ЖНВЛП | Использовать только исходное `Да/Нет` |
| `controlled_substances` | Наркотические/психотропные вещества | Отдельный признак контроля |
| `orphan` | Орфанный | Отдельный признак |
| `source_status` | Статусный раздел | В рыночном отчёте всегда `Действующий`; отдельная графа не нужна |
| `source_file`, `source_row` | Происхождение | Трассировка до исходной строки |

## Подсчёт

После проверки точного значения МНН берите все соответствующие записи только из раздела `Действующий`. Каждое точное РУ считайте один раз. Отдельно показывайте лекарственные препараты и записи, где форма выпуска буквально содержит `субстанц`.

Основные рыночные показатели для позиции Product List:

- `Количество конкурентных препаратов на рынке` — уникальные РУ лекарственных препаратов с нужной формой;
- `Производители на рынке` — уникальные держатели РУ среди тех же конкурентных препаратов.

Не сравнивайте цепочки переоформления с другими статусными файлами. Отдельного поля перерегистрации в выгрузке нет; не выводите её автоматически из нормативной документации.
